# The Legend of Zelda: A Link to the Past

A fully functional browser-based recreation of The Legend of Zelda: A Link to the Past, featuring all 12 levels (3 Light World + 9 Dark World) with complete gameplay mechanics.

## 🎮 Features

- **Complete 12-Level Adventure**: 3 Light World levels and 9 Dark World levels
- **Full Combat System**: Sword fighting with enemies and bosses
- **Item Collection**: Rupees, hearts, keys, chests, and special items
- **Character Progression**: Health system, inventory management
- **Authentic Gameplay**: Movement, combat, and exploration mechanics
- **Boss Battles**: Unique boss in each level with multiple phases

## 🚀 How to Play

1. **Start the Game**: Open `index.html` in any modern web browser
2. **Controls**:
   - **WASD** or **Arrow Keys**: Move Link around
   - **SPACE**: Attack with sword
   - **E**: Interact with chests and objects
   - **ESC**: Pause/Menu
   - **R**: Restart (when game over)

3. **Objective**: 
   - Explore each dungeon level
   - Defeat enemies and collect items
   - Find keys to open locked chests
   - Defeat the boss to complete each level
   - Progress through all 12 levels to complete the game

## 🗺️ Level Progression

### Light World (Levels 1-3)
1. **Eastern Palace** - Introduction level with basic enemies
2. **Desert Palace** - Features pit traps and desert-themed challenges
3. **Tower of Hera** - Multi-level tower with magical enemies

### Dark World (Levels 4-12)
4. **Palace of Darkness** - Dark world introduction
5. **Swamp Palace** - Water-themed challenges
6. **Skull Woods** - Forest maze with complex enemy patterns
7. **Thieves' Town** - Town setting with archer enemies
8. **Ice Palace** - Ice-themed with magical challenges
9. **Misery Mire** - Swampland with mixed challenges
10. **Turtle Rock** - Rocky cavern environment
11. **Ganon's Tower** - Most challenging pre-final level
12. **Final Boss** - Ultimate confrontation arena

## 🛠️ Technical Details

- **Pure JavaScript/HTML5 Canvas** - No external dependencies required
- **Modular Architecture** - Clean separation of game systems
- **Object-Oriented Design** - Proper encapsulation and inheritance
- **Cross-Browser Compatible** - Works in all modern browsers

## 🎯 Game Elements

- **Link (Player)**: Green character with directional sprites and animations
- **Enemies**: Various types including soldiers, archers, and wizards
- **Bosses**: Unique boss in each level with special abilities
- **Items**: Collectible rupees, health hearts, keys, and treasure chests
- **Environment**: Interactive dungeon environments with obstacles

## 🔧 Debug Commands

Open browser console and type `debugZelda.help()` for debug commands:
- `debugZelda.gotoLevel(1-12)` - Jump to any level
- `debugZelda.heal()` - Restore full health
- `debugZelda.giveItem(type, amount)` - Give items to player
